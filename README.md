# Pavan Kumar Goud Amikula — portfolio

Public portfolio: https://pavan-amikula.github.io/

## Edit your content
Open **content.json** on GitHub and choose the pencil icon. Edit your name, introduction, about text, skills, education, internship, or project explanations and report links. Commit your changes to main. GitHub Actions rebuilds and publishes the site automatically. Keep the JSON syntax valid; Download raw file gives you a backup.

The 3D sculpture, project filters and keyboard controls run in the browser. All portfolio text is also rendered into the HTML during the build, so visitors and crawlers can read it before JavaScript loads.

## Develop locally
Use Node.js 22.13 or newer. Run `npm ci`, then `npm run dev`. Run `npm run build` to generate dist. Reports link to their original public GitHub files and retain coauthor credits.

## Search indexing
The site provides a canonical URL, full-name title, description, Open Graph metadata, Person/WebSite/ProfilePage JSON-LD, robots.txt and sitemap.xml. Add https://pavan-amikula.github.io/ as a URL-prefix property in Google Search Console, verify ownership with Google's HTML file or meta tag, and submit sitemap.xml. Ranking and indexing are controlled by Google; these files do not guarantee a position or indexing.
